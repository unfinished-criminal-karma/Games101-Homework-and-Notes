## 二、第一步：装 CMake

**方式 A（推荐，一行命令，管理员 PowerShell）**
```powershell
winget install Kitware.CMake
```

**方式 B**：去 `https://cmake.org/download/` 下 `cmake-x.x.x-windows-x86_64.msi`

装完**把终端/Rider 全部关掉重开**，验证：
```powershell
cmake --version
```

## 三、第二步：装 OpenCV

下载 **`opencv-4.x.x-windows.exe`**（自解压包，约 200-300 MB）：

- GitHub：`https://github.com/opencv/opencv/releases`（需要加速器）
- SourceForge 镜像：`https://sourceforge.net/projects/opencvlibrary/files/`（国内有时能直连）

**双击解压到 `D:\opencv`**（⚠️ 路径不要有中文和空格）。

解压成功的标志 —— 存在这三个目录：
```
D:\opencv\build\include\opencv2\
D:\opencv\build\x64\vc16\lib\
D:\opencv\build\x64\vc16\bin\
```

> **vc16 = VS2019，vc17 = VS2022。** 你的 VS2022 能直接链接 vc16 的库（MSVC 14.x ABI 兼容），不用纠结。

## 四、第三步：Rider 打开工程

1. Rider → **Open** → 选 `F:\Practice\GAMES101-hw3\CMakeLists.txt`
2. 提示配置工具链 → 选 **Visual Studio**（一般会自动识别到 `F:\VSCode_Apply`）
3. `Settings → Build, Execution, Deployment → CMake` → 确认 **CMake executable** 指向刚装的 cmake.exe
4. 如果 OpenCV 解压到了别的地方，改 `CMakeLists.txt` 第 12 行的 `OpenCV_DIR`

**编译**：Rider 右上角选 `Rasterizer` 目标 → Run。程序需要命令行参数，直接在 Run Configuration 的 Program arguments 里填：

```
output.png normal
```

可选模式：`normal` / `phong` / `texture` / `bump` / `displacement`

## 六、可能踩的坑

| 现象 | 原因 / 解法 |
|---|---|
| `Cannot find source file: ...` | CMakeLists 里的源文件列表漏了；本工程只有 4 个 .cpp（`Texture.cpp` 是空文件，**正常**） |
| `无法打开 Eigen/Dense` | `EIGEN_ROOT` 路径不对，应指向**包含 `Eigen` 子目录的那一层** |
| `find_package(OpenCV) fails` | `OpenCV_DIR` 应指向 `opencv/build`（里面有 `OpenCVConfig.cmake`） |
| 编译过了，运行报缺 `opencv_world4xx.dll` | CMakeLists 里已加自动拷 dll 的步骤；仍不行就手动把 `D:\opencv\build\x64\vc16\bin` 加进系统 PATH |
| 输出图片上下颠倒 | OpenCV 的 y 轴与屏幕相反，这是后面要处理的问题 |
| Rider 里 CMake 不刷新 | `File → Reload CMake Project` |

## 七、备选方案（如果 OpenCV 死活下不下来）

OpenCV 在本作业里只干两件事：`cv::imread` 读贴图、`cv::imwrite` 存结果。
理论上可以用 **stb_image / stb_image_write**（两个单头文件，约 300 KB）替换掉，彻底免掉 300 MB 下载 —— 代价是**偏离官方框架**，将来对照网上的答案/教程时会有差异。
